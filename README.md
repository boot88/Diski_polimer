# НСК Макстар — покраска дисков

Лендинг мастерской «НСК Макстар» для записи на порошковую (полимерную) покраску колёсных дисков в Бердске.

## Локальный запуск

```bash
cp .env.example .env
composer install
php artisan key:generate
npm ci
npm run dev
php artisan serve
```

Для работы формы укажите в `.env` почтовые параметры, получателей и MAX:

```dotenv
LEAD_TO_EMAILS=polimer@happypils.ru,povisok888@gmail.com
MAX_BOT_TOKEN=
MAX_USER_ID=
```

Браузер принимает исходное фото до 25 МБ и сжимает крупные изображения перед отправкой. Серверный лимит — 5 МБ. Без JavaScript загружайте фото до 5 МБ. Заявка доставляется независимо на настроенные email и в MAX. При проблеме одного канала другой продолжает работать. Для безопасной проверки без вывода секретов:

```bash
php artisan lead:test-delivery
```

## Два дизайна

Внизу сайта переключатель «Текущий / Новый · MAXTAR». Выбор сохраняется в браузере.
Для прямого просмотра: `/?design=classic` и `/?design=modern`.
Переключение не перезагружает страницу: текст заявки, фото и выбранное покрытие сохраняются.
Диаметры, цены и покрытия задаются в одном месте: `config/wheels.php`.

Визуальные ориентиры второго дизайна: [ColorWerks](https://colorwerks.co/) и
[USA Wheel Repair](https://usawheelrepairpros.com/). Использованы собственная компоновка
и изображения из проекта; обещания, отзывы и фотографии конкурентов не переносились.

## Домен

При переносе на `www.maxtar-nsk.ru` задайте `APP_URL=https://www.maxtar-nsk.ru`
и направьте корень сайта на папку `public`. После изменения выполните
`php artisan optimize:clear`. Canonical, Open Graph и ссылка в уведомлениях берутся из `APP_URL`.
Карта сайта находится в `public/sitemap.xml`.

После обновления этой ветки установите зависимости из зафиксированных файлов:
`composer install --no-dev --optimize-autoloader` на сервере, `npm ci` для локальной сборки.
Обновлены совместимые версии Laravel 12, HTTP/почтовых библиотек и инструментов сборки.
